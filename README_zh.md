# 2048 AI 软件 - Meter 2048 Auto

面向 **无尽模式 2048** 的辅助软件，支持 **3×3 / 4×4 / 5×5** 三种棋盘。AI 为纯 C++ 算法实现（不使用任何终局表 / AI DLL），边玩边实时求解。

[English (README.md)](README.md)

## 功能特色

- **AI 自动操作** — 自动走出最佳一步，支持速度滑动条与三档计算深度（快 / 均衡 / 深）。
- **实时预测面板** — 方向概率条、单步偏差、里程碑达成率（如 8192 / 16384 / 32768）实时刷新。
- **智能撤回** — 连续撤回保护，死局重试自动跳过导致死局的那一步。
- **历史记录（压缩存储）** — 每局保存为紧凑的 `.dat` 回放文件，每一步仍可逐帧还原（类 VRS 格式）；支持导入 / 导出 / 单条删除 / 回放。
- **计时模式 & 挑战 2048** — 竞速玩法，会话状态完整持久化。
- **局面编辑 & 自定义主题** — 自由摆盘，主题配色支持导入 / 导出。
- **棋盘自由切换** — 3×3 / 4×4 / 5×5 随意切换，分数互不丢失。
- **中英双语界面** — 日志轻量化。

## 从源码构建

环境要求：**Visual Studio 2022**（含「使用 C++ 的桌面开发」工作负载）、**SFML 2.6.1**（Visual C++ 17，x64）、Windows 10 及以上。

1. 克隆本仓库。
2. 从 <https://www.sfml-dev.org> 下载 SFML 2.6.1 并解压，例如 `C:\SFML-2.6.1`。
3. 用 VS2022 打开 `2048 game pro/2048 game pro.vcxproj`。
4. 项目属性（**Release | x64**）：
   - C/C++ → 常规 → **附加包含目录**：`C:\SFML-2.6.1\include`
   - 链接器 → 常规 → **附加库目录**：`C:\SFML-2.6.1\lib`
   - 链接器 → 输入 → **附加依赖项**：`sfml-audio.lib;sfml-graphics.lib;sfml-network.lib;sfml-system.lib;sfml-window.lib;openal32.lib;opengl32.lib;winmm.lib`
5. 生成 **Release | x64**。
6. 将 `C:\SFML-2.6.1\bin` 下的 DLL（必要时加上 MSVC 运行库 DLL）复制到 exe 旁，并保留 `game fonts` 字体目录。
